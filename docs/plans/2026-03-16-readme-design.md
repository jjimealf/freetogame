# README Design

**Objetivo**

Añadir un `README.md` equilibrado y útil para personas nuevas en el repositorio, combinando una explicación funcional breve de la app con la información técnica necesaria para desarrollarla, ejecutarla y generar la app Android.

**Enfoque aprobado**

- Explicar qué es `FreeToGame` y qué casos de uso cubre.
- Resumir las pantallas y módulos principales sin convertir el documento en una guía extensa.
- Documentar requisitos reales del entorno: `Node 24`, `JDK 21` y `Android SDK`.
- Incluir pasos de instalación, arranque web, sincronización con Capacitor y compilación Android.
- Añadir notas importantes sobre las APIs externas y el comportamiento del PDF en web y Android.

**Resultado esperado**

Un `README.md` en español, corto pero práctico, que sirva tanto para onboarding funcional como para puesta en marcha técnica del proyecto.
